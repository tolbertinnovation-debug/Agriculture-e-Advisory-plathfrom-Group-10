FEATURE PHONE

Dial *347# — no internet needed

Most rural farmers in Liberia use basic phones. AgriConnect works on any phone through USSD menus, SMS alerts and voice calls.

  • Type *347# and press SEND (or the green key).
  • Reply with a menu number.
  • 0 = back, 00 = main menu.

Short code shown is a placeholder; the real code is assigned by the telecom operators (Lonestar Cell MTN / Orange Liberia).
